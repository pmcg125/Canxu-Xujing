# 残叙·残念：首版需求基线

2026-11-01 用户确认开工。Android 优先，保留其他平台扩展空间。新建原创工程，以已还原的 PiuPiu 2.7.9 行为和交换格式为参考。

## 已确认

- 原生 Material Design 3 宿主界面；角色卡 HTML/CSS/交互保留作者样式。
- 气泡/阅读模式切换，共用同一会话数据。
- 本地角色与多角色群聊、用户人设、预设、正则、世界书、宏、变量、候选回复、编辑/续写/回溯、摘要及长期记忆。
- OpenAI 兼容自定义 API，支持 URL、请求头、模型及生成参数。
- 本地与远程 Embeddings 均支持，模型权重不随安装包分发；提供来源下载页及手动模型包导入，优先轻量中文模型。
- 模型/配置绑定独立向量索引；换模型重建，保留聊天原文。
- PiuPiu PNG角色卡、资料JSON、聊天JSON、设置JSON、角色会话ZIP双向兼容为目标；保留未知字段与原始嵌套数据。
- 保留 HTML/MVU/TavernHelper 实际接口子集的兼容目标；实现状态必须逐项记录，不将支持文件导入等同完整脚本兼容。

## 不纳入首版

账号、邀请、VIP、原版许可/签名/固定凭据、社区/市场/在线聊天室、Live2D。TTS 与生图延期。

## 工程阶段边界

本次先形成可编译可安装的开发版本和真实基础链路。完整行为等价需要后续以用户授权的代表性资料逐项核查，未完成项目留在兼容矩阵中。按会话约束，本轮不添加或运行测试，不访问真实模型端点、不安装到手机。

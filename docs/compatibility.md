# 交换格式与执行兼容范围

参考对象：PiuPiu 酱 Android 2.7.9。界面和宿主使用 Kotlin/Compose；部分角色卡兼容模块复用恢复的前端代码，来源记录见 `THIRD_PARTY_NOTICES.md`。不包含原应用凭据、许可服务或模型。

“已实现”表示代码已有对应路径，不表示已用用户全部资料完成双向核对。

## 交换格式

| 类别 | 当前实现 | 尚待核对 |
| --- | --- | --- |
| PNG 角色卡 | `chara` / `ccv3`；tEXt、iTXt、zTXt；Base64；PNG CRC 检查；保留原始嵌套 JSON，导出 PNG | 非标准 PNG、第三方扩展和多媒体卡 |
| 世界书 JSON | 数组 / 对象条目、常见字段别名、原始字段保存和导出 | 特殊条目结构及跨应用扩展 |
| 预设 JSON | prompts、prompt_order、内容与注入位置；保留未知字段 | 服务端专有采样参数与旧版扩展 |
| 正则 JSON | 常见脚本结构、角色内嵌与独立正则 | JS 与 JVM 正则行为差异，见执行范围 |
| 人设 / 文风 JSON | 原始 JSON 保存、会话绑定、文本注入与导出 | 第三方包装格式 |
| 聊天 JSON | 消息、角色、候选回复、变量及额外字段 | 多角色特殊成员记录与复杂状态 |
| 设置 JSON | PiuPiu 设置原文保存、资料迁移；残叙·残念扩展设置；移除常见鉴权信息 | 不逐项复刻原版外观/服务配置 |
| PiuPiu ZIP | v1 manifest、roles.ndjson、sessions.ndjson、messages/*.ndjson、media；导入 / 导出 | 全量真实样本回导原应用，特殊群聊及媒体引用 |
| 残叙·残念备份 | PiuPiu 文件结构加 `xujing-state.json`，保存残叙·残念专有设置 | 将来版本迁移 |

导入采取合并方式。冲突 ID 分配新值并重连角色、群组成员、发言人、会话绑定及摘要进度；复杂扩展内部的任意自定义引用尚不保证全部重写。附件字符串只有与已知媒体键完全匹配时才替换，覆盖资料库正文及扩展字段，本地头像可显示并再次导出。设置导出同步空资料列表和文风，已删除的资料不会从旧设置中恢复。

读取大小限制：单个资料文件 256 MiB，ZIP 展开 384 MiB，单项 64 MiB，JSON 32 MiB，NDJSON 单行 8 MiB，文件数 20,000。当前导入和导出会在内存中形成中间对象，大型媒体备份仍需后续改为完整流式处理。

## 提示词和会话

| 能力 | 当前实现 | 限制 |
| --- | --- | --- |
| 角色与群聊 | 描述、性格、场景、示例、系统提示、后置指令、人设；群聊指定本轮成员 | 没有原版云端内部推理和隐藏提示词；多角色一轮生成一人 |
| 世界书 | 常驻、主键/副键、正则键、递归、预算、概率、互斥组、位置/深度、sticky/cooldown 状态 | 部分格式别名和 token 估算与原版不同 |
| 预设 | prompts / prompt_order、marker、注入位置/深度/角色、示例拆分；可选套用预设采样参数 | 默认使用连接参数；开关启用后支持温度、top_p、惩罚、输出上限、seed、停止序列；服务商专有字段仍由连接配置 |
| 宏 | 常用角色/用户/时间/随机/变量；块式赋值、嵌套、条件分支、字符串拼接、trim | 部分作用域和边缘语法待核对；不是完整 SillyTavern 宏语言 |
| 正则 | 输入、输出、显示、世界书等阶段，深度和启用过滤；查找式宏支持原样/转义替换 | JVM Regex；部分 JS flag、替换语法和高级语法存在差异 |
| 变量更新 | JSON Patch、基本 MVU / `_.set` / `_.assign` / `_.remove` 文本解析、候选快照 | 不执行原始 JS；没有完整 Zod schema / 任意 MVU 扩展 |
| 候选与回溯 | 重生成新增候选、选择候选、续写、编辑、删除、回溯；清理摘要/索引 | 对中间历史的改动不能自动重演任意脚本副作用 |
| 摘要 | 手动生成及可选自动摘要，支持独立 API；保留近期原文、按积累的旧角色回复触发、按上下文分批增量整理，记录进度 | 自动摘要在发送新消息前触发，无后台定时任务；长记录手动摘要可多次处理。真实摘要质量取决于自定义模型 |
| 上下文 | 近期消息裁剪、摘要、世界书、变量、长期记忆 | token 使用字符估算，超长固定提示词会提示，不静默截断角色资料 |

会话设置中的“使用预设采样参数”和“自动整理剧情摘要”默认关闭。自动摘要额外调用摘要连接；未指定时复用聊天连接，但使用连接自身的采样参数。自动摘要失败会保留旧摘要并继续聊天，提示词详情保留失败原因；停止生成也会取消摘要。编辑、删除、切换候选或回溯历史会清除摘要及其进度。

变量更新块支持 `Update`、`UpdateVariable`、`UpdateMVU`、`VariableUpdate`、`VariablesUpdate` 及 `JSONPatch`（包括下划线或连字符），非嵌套的不同类型块按原文顺序处理。支持常见 `lodash` 命令、数组或对象索引、数组形式路径、部分 JSON 形式的命令、带说明的数值对及相对于 `stat_data` 的 JSON Patch 路径。未支持的 JSON 操作和作用域会保留原文。当前解释器仍只支持部分命令和参数，块内操作按事务提交；日期加法、完整 schema 规则、嵌套更新块、其他变量作用域和原版事件链仍有差距。

JSON Patch 的 `path` 及 move/copy 的 `from` 必须提供字符串；非法输入使整个更新块回滚并保留原文，不会将缺失路径当作根路径。数值 `delta` 和描述对依照已确认的原版行为处理。

## HTML 和脚本

- 聊天正文按 Markdown、普通代码围栏、HTML 片段和完整 HTML 文档分段呈现；完整文档保留自己的 `head/body`。内联代码和未闭合围栏中的 HTML 不执行，生成流式期间不创建 HTML WebView。HTML / CSS 在 WebView 中按作者样式呈现；允许脚本后可自动测量高度。
- `TavernHelper` / `SillyTavern.getContext` 的上下文、变量、消息读写、发送和生成提供基础接口。
- 已抽取原版 MVU 数据接口和 Zod schema 事件钩子，使用本地 Zod 4.4.3。支持会话和消息候选作用域、`mag_*` 事件值与旧名称别名；`setMvuVariable` 与原版一样修改传入的数据，保存需要显式调用替换接口。变量写入落盘成功后返回，旧变量或旧候选写入会被拒绝；其他变量作用域会明确报错。
- Kotlin 侧已有 InitVar 加载、历史/候选重放以及 `parseMessage` / `reloadInitVar` 宿主路径；完整 MVU 命令和宿主生成后的 Zod 校验事件链仍未对齐。`waitGlobalInitialized('Mvu')` 等待页面快照同步，不能作为全部原版生命周期已对齐的保证。
- 本地 EJS 3.1.10 引擎支持允许脚本的消息 HTML 模板，以及 `EjsTemplate.render/evaluate`、条件、异步模板、`getvar/setvar` 和错误回退。显示渲染的变量变化只返回到结果，不隐式保存；卡片可显式提交 `result.variables`。世界书/预设及生成前后的模板阶段尚未接通；文件模板需要显式 includer。
- `scripts/openai.js` 和 `scripts/utils.js` 使用恢复的前端模块，并通过残叙·残念适配当前会话与生成接口。生成请求只适配现有消息数组；中途取消信号和全部原版选项尚未接入。
- `scripts/world-info.js` 使用恢复的前端模块；已接入资料库世界书读取、创建、保存、删除及当前角色主/附加世界书绑定。脚本创建的世界书限定在当前会话，导入备份时会重新关联。返回的条目仅适配常见字段，尚未完整复刻所有原版字段和嵌入式世界书。
- 会话限定世界书同时映射至 PiuPiu 会话的 `dynamicWorldBooks`；原版格式导入和残叙·残念备份重复导入时会重新关联会话，避免作为全局资料泄漏。同名资料优先使用当前会话的世界书。
- `scripts/preset-manager.js` 使用恢复的前端模块；可列出、按需加载和为当前会话选择预设。同步读取预设内容需要先异步 `loadPreset`；选择方法是异步的。脚本创建、修改、删除预设尚未接入。
- 根路径 `/script.js` 也提供恢复模块；仅实现其所依赖的部分宿主行为，并非完整复刻整个前端运行环境。
- 世界书或预设修改在生成期间被拒绝；脚本修改在写入本地资料后才报告成功。
- 消息脚本按文档顺序加载，关闭页面时清理待处理请求和事件。另有一个会话级隐藏 WebView 管理角色独立脚本树，每个角色脚本在自己的隐藏 iframe 中运行：支持常见 modern/legacy 结构、禁用文件夹、按序加载和会话内逐项停用；需同时开启全局脚本与会话独立脚本开关。消息离屏不会重建会话脚本，关闭会话或更改脚本配置时释放运行环境。每脚本 iframe 隔离已完成源码接入，尚未构建或在设备上运行验证。
- 会话脚本可监听 `generation_started`、`chat_completion_prompt_ready`、`generate_after_data`、`js_generation_started`、`js_stream_token_received_incrementally`、`js_stream_token_received_fully`、`message_received` 和 `generation_ended`。两个生成前事件分别通过 `chat` 和 `messages` 数组改写最终请求；生命周期和流事件按原版参数数组传递。消息接收事件仅在保存成功后派发；生成事件执行期间继续拒绝历史/变量写入与递归发送，避免状态交错。
- 脚本宿主请求与事件有超时；初始化失败会记入 Android 日志，单个 iframe 的事件异常不会阻断其他脚本。生成前宿主事件校验失败时不发送该轮请求。停止会取消宿主等待并派发 `generation_stopped`；已运行的 JavaScript 异步副作用仍需脚本配合停止。角色脚本按钮已接入输入区，运行时广播会依会话脚本、消息索引和 HTML 片段顺序分发给当前已挂载的卡片。所有 DOM / 生命周期语义、全部依赖库及第三方扩展仍未完整接通。
- 脚本默认关闭。开启后卡片可以联网，也可以通过有限接口调用用户配置的模型服务。不能读取宿主 API 密钥或 Android 文件。

复杂状态栏、互动卡、脚本驱动世界书和基于外部扩展的卡片仍是后续兼容工作的重点。

## 长期记忆

本地 ONNX 支持 BERT WordPiece、`input_ids` / `attention_mask` / `token_type_ids` 的 INT64 输入，float 输出，CLS 或 mean pooling，归一化与余弦检索。不是通用所有 ONNX/tokenizer 引擎。远程使用 OpenAI 兼容 `/embeddings`。

按模型/配置分开保存索引；文本变化以块哈希失效；近期原文不重复作为长期记忆注入。更换模型后重建对应索引。原备份的历史向量作为未知数据保存，不直接混用到新模型索引。

每个会话可选择使用最近 1–30 条消息组成检索查询，默认 3 条；查询文本过长时先按字符保留末尾，本地分词仍受模型输入长度限制。先按相似度选择片段，再按聊天中的原始顺序注入。同一片段的不同分块也保持先后顺序。原版逐条查询再取最高相似度的行为尚未对齐。

尚未在真机上执行模型推理或评估召回质量、耗时与内存占用。

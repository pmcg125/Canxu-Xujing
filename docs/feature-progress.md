| 功能 | 入口与行为 | 边界 |
| --- | --- | --- |
| 聊天记录搜索 | 聊天菜单 → 搜索聊天记录；忽略大小写搜索当前会话，展示说话人和匹配片段，点击跳转 | 搜索原始消息文本，不解析 HTML 页面中的视觉文本；不跨会话 |

| 气泡外观 | 会话设置 → 阅读外观；透明度 10%–100%，圆润 / 方角样式 | 阅读模式仍无气泡背景；未复刻原版所有样式 |
| 回复建议 | 输入区 → 回复建议；额外调用当前聊天 API，生成可选用户回复；点选仅填入输入框 | 最近 12 条原文作为参考；结果不写入聊天历史；会话切换、生成新回复或历史修改会清除旧建议 |
| 独立脚本 | 全局允许角色卡脚本后，在会话设置开启独立脚本；展示脚本数量与单项开关；每个脚本使用独立隐藏 iframe；接入按钮元数据及输入区事件按钮 | 仅适配常见 TavernHelper 树形结构与 JavaScript；TypeScript 转译未接入，iframe 方案尚未运行验证 |
| 生成事件 | 会话脚本监听生成前后与流式事件，生成前可改写消息数组；按参数数组转发给会话脚本和已挂载 HTML WebView；提示词详情反映最终请求 | 并非完整 MVU/Zod 生成链；异步取消副作用仍需脚本配合 |

独立脚本按启用顺序载入，使用本地 EJS、Zod、MVU 和已保留的兼容模块。新会话独立脚本默认关闭。脚本配置变化、角色切换或会话关闭会释放旧环境与等待任务。脚本可联网以及通过现有宿主接口请求操作当前会话，不会得到宿主密钥或 Android 文件接口。

生成前事件的最小数据契约：

```javascript
eventOn(tavern_events.CHAT_COMPLETION_PROMPT_READY, payload => {
  // payload.chat 为 { role, content, name? } 消息数组。
  payload.chat.push({ role: 'system', content: '保持人物的叙事视角一致。' });
});
eventOn(tavern_events.GENERATE_AFTER_DATA, payload => {
  // payload.messages 为上一阶段返回的数组，修改后用于实际 API 请求。
});
```

## 2026-11-04 本轮源码接入

按 PiuPiu 细节差异计划补齐：

- 聊天内容现在可在 Markdown、普通代码围栏、HTML 片段和完整 HTML 文档之间分段渲染。内联反引号中的标签不会运行；未闭合围栏和流式中的 HTML 保持文本，生成结束后再创建 WebView。完整文档保留自己的 head/body；脚本仍受全局卡片脚本开关控制。
- 会话事件按消息索引和片段顺序派发到当前已挂载的 HTML WebView；会话脚本先运行。宿主事件使用完整参数数组，包括 generation started、stream tokens、message received 和 generation ended。单个 WebView 失败或超时会继续使用前一份参数。
- 接入角色卡脚本按钮元数据、PiuPiu 按钮事件名，以及输入区按钮调用。只展示可见且有名称的按钮；生成或忙碌期间禁用。
- 编辑消息按消息角色和深度重跑对应输入 / 输出正则阶段，只执行显式允许编辑时运行的规则，不重复应用变量更新副作用；同时将当前候选的原始文本与 swipe 来源同步。
- 世界书递归预算、零扫描深度和延迟递归步数按解析后的数值处理；变量对象合并保留递归语义，但数组以新数组整体替换。

本轮仅完成源码接入和静态审阅；按用户要求未构建、未运行测试、未安装或启动应用。每脚本 iframe 隔离已完成源码接入，但未运行验证；全部异步事件副作用、更多 HTML DOM 生命周期行为及代表性真数据验证仍未完成。

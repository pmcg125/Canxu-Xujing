## 4. 发现并修复的问题

| # | 缺陷 | 位置 | 处理 |

| 1 | 编译失败：`Int?` 与 `Int` 比较 | `core/.../WorldbookEngine.kt:217` | 改为 `budget != null && spent + estimated > budget`，保留「比例 0 且 cap 0 = 无上限」语义 |
| 2 | `build.ps1` 启动即失败：无 BOM 的 UTF-8 `.ps1` 被 PowerShell 5.1 按 cp936 解析 | `tools/Sync-DependencyCache.ps1` 等 4 个脚本 | 统一补 UTF-8 BOM；5 个 `.ps1` 解析全部通过 |
| 3 | 两个 Node 夹具仍按三参数 `XujingBridge.request(id,method,payload)` 打桩 | `tools/test-card-modules.cjs`、`tools/test-card-runtime.cjs` | 对齐为四参数；补 `broadcastRuntimeEvent` / `parseMvuMessage` 分支；`waitGlobalInitialized` 前先同步快照；`parseMessage` 断言改为已实现行为 |
| 4 | 桥接同步抛异常时 180s 定时器与 `pending` 条目不清理 | `app/src/main/assets/card-runtime.js` | 用 `try/catch` 清理并 reject |
| 5 | 未闭合代码围栏：围栏标记被吞掉并留下空白带 | `app/.../ui/MessageContentParser.kt` | 未闭合围栏按「代码块延伸到文末」输出 `MessageSegment.Code` |

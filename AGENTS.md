# 残叙·残念

Android first roleplay app. Kotlin core has no Android dependencies. Native Jetpack Compose Material 3 shell; card HTML/CSS keeps author styling. No account, VIP, invitation, community, market, Live2D, bundled weights, or proprietary service credentials. TTS and image generation are deferred.

Preserve PiuPiu 2.7.9 exchange data and unknown nested fields. Treat file compatibility and execution compatibility as separate milestones. Do not claim full compatibility before representative data has been checked.

Do not add or run tests unless the user requests testing. Compiling/packaging is allowed. Do not install or launch on a phone without a current implementation request to do so. Keep toolchains and project files on D: where possible.

User download preference: prefer mirrors, then official sources as fallback. Use resumable downloads and retain partial files; verify available upstream checksums. Gradle resolves through Aliyun mirrors first. Model pages and the manual package script prefer hf-mirror.com, with Hugging Face as fallback. Use tools/Download-Resumable.ps1 for explicit artifact downloads. Gradle's built-in dependency downloader is cached but is not claimed to provide persistent byte-range resumption; manually fetch interrupted large artifacts with the helper when needed.
